The journey through the code

  1. Upload the deck browser

    app/page.tsx takes the file. readDeck in lib/client/deck.ts calls checkFile (20 pages / 20 MB) and extractSlides from lib/pdf.ts to pull slide text, renders previews and keeps an image only for slides with little text.
    lib/pdf.tslib/client/deck.tslib/text.ts

  2. Make the board serveragent

    app/api/board/route.ts requires OPENAI_API_KEY (requireEnv, lib/env.ts), asks the agent, then runs repairBoard and validateBoard from lib/board.ts: 5–7 cues, 3–4 acts, ≤3 gaps, 1–3 word labels. The agent stores it with save_board.
    lib/board.tslib/coach.tsagent/instructions.mdlib/record.ts

  3. Save the session browser

    createSession posts to the board route; the new id (lib/session.ts) opens app/s/[id]/page.tsx. lib/client/store.ts saves a LocalSession under pitchbooth:<id>, dropping previews if storage is full.
    lib/client/store.tscomponents/steps/BoardStep.tsxcomponents/Board.tsx

  4. Walk through the cues browseragent

    components/steps/WalkthroughStep.tsx sends each spoken or typed answer to app/api/coach/route.ts (rate limited by limitResponse). Replies are spoken through hooks/useSpeaker.ts → app/api/tts/route.ts. The agent can rename a cue (update_cue → renameCue) and keeps notes (log_note).
    lib/client/api.tsagent/tools/update_cue.tsagent/tools/log_note.ts

  5. Timed run browser

    components/steps/RunStep.tsx picks the level with levelForRun. hooks/useListener.ts gets a token from app/api/stt-token/route.ts, streams 16 kHz PCM (lib/stt.ts) to AssemblyAI, and feeds words to createTracker in lib/tracker.ts, which marks cues reached, skipped or recovered and counts stalls. lib/nudges.ts watches pace.
    hooks/useRun.tslib/client/run.tslib/tracker.tslib/nudges.ts

  6. Score browseragent

    The agent grades content against the founder or school rubric; scoreRun in lib/score.ts adds measured pace, time, recovery and filler, and topFixes picks three. The run is logged with log_run and shown in components/steps/ScoreStep.tsx.
    lib/score.tsagent/tools/log_run.ts

  7. Takeaway browser

    components/steps/TakeawayStep.tsx prints the board, opener, closer, practice plan, fixes and run history.

Practice to reuse

Keep the rules in pure, tested functions and let routes and the agent call them. Here every new or repaired board goes through validateBoard and every rename through isValidLabel in lib/board.ts, which lib/board.test.ts covers, so a bad model reply never reaches the screen. Reuse the pattern for any AI output that the UI depends on.
